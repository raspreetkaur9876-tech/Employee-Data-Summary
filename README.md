# Employee Data Summary

## Project Description
This project analyzes employee information
using Microsoft Excel.

## Tools Used
- Microsoft Excel
- PivotTables
- Excel Formulas
- Charts

## Project Objectives
- Analyze employees by department.
- Calculate average salary.
- Analyze employee job roles.
- Create charts and summaries.

## Analysis Performed
1. Employee Count by Department
2. Average Salary by Department
3. Employee Count by Job Role

## Conclusion
This project helps summarize employee
information and understand workforce distribution.
